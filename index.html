This page is Ghana-only (one page per country): it is independent of the main site and needs no changes to bee77777.com. Just register it as a Web App of the Ghana Bot and paste its public address. Proposed hosting: GitHub Pages, repository bee77777-ghana-miniapp → https://ethansen0527.github.io/bee77777-ghana-miniapp/ (pending creation).

  1. Open @BotFather in Telegram and send /newapp.
  2. Choose the Bot: @Bee77777GhanaBot (proposed name, to confirm when creating it).
  3. Write the title and description BotFather asks for (in English, for Ghana).
  4. When it asks for the Web App URL, paste the public address of this page once published.
  5. As the short name use: play.
  6. Confirm. The MiniApp becomes accessible as t.me/Bee77777GhanaBot/play and accepts attribution with ?startapp=ghana_ads.

https://t.me/Bee77777GhanaBot/play?startapp=ghana_ads

The link must always carry /play: without the short name it opens the previous main app, not this MiniApp. Variants per channel: change only the code — https://t.me/Bee77777GhanaBot/play?startapp=ghana_ads_tg for Telegram ads, https://t.me/Bee77777GhanaBot/play?startapp=ghana_ads_fb for Facebook. Code rules: letters, numbers, _ and -, max 512 characters in startapp.

2 · How attribution is read on this page

When it opens, the page reads the code in this order: Telegram.WebApp.initDataUnsafe.start_param → tgWebAppStartParam parameter in the URL (query and hash, including inside tgWebAppData). The code is validated (letters, numbers, _, - only; max 512) and, if invalid or missing, it shows “no code”. The “Follow the Bot” button reuses that same code in ?start=<code> when it is 64 characters or less; if the code is longer, the button uses the short code bot, because ?start= accepts at most 64 characters.

Data separated by country: this page stores nothing. Ghana's data lives in the Ghana Bot (its own user database) and in the Ghana shared sheet; it is not mixed with Peru, West Africa or Chile, which each have their own Bot, their own sheet and their own page.
